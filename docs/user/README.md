Cairn Core v1 starts with local markdown files, validation, local SQLite search, MCP, and blob-backed sync. Pilot helpers add full readiness checks, low-friction capture, repo references, ADO candidate capture, VS Code commands, and local health reporting without adding hosted services. The default user path does not require CocoIndex, Postgres, pgvector, Docker, or a remote indexer.

For the no-service local smoke and sample config, see the [Local Development Harness](../../deployments/local-dev/README.md). For the current v1 indexing boundary, see [Indexing Boundary And Query Contract](../adr/ADR-indexing-query-boundary.md).
