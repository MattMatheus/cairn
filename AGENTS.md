# AGENTS

This project uses Flywheel as its local work harness.

## Work Harness
- Start by reading `Flywheel/flywheel.yaml`.
- Then follow `Flywheel/flywheel/AGENTS.md` for agent operating rules.
- Use the prompts, roles, backlog lanes, artifacts, and process docs configured under `Flywheel/flywheel/`.

## Local Copy
`Flywheel/` is vendored into this repository as a local harness copy. Treat it as part of this workspace unless a human explicitly asks to resync it with an upstream source.

## Project Layer
Product-specific planning, implementation notes, and team decisions for Cairn should live outside the Flywheel harness unless they are deliberate changes to the harness itself.
